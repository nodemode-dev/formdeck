# Template catalog

The 67 built-in templates of formdeck 0.2.0 in 9 categories, with their look and theme fonts (titles / body). `list_templates` is the authority: it also lists templates the person imported (category Imported) and the person's default. Every built-in template has all 21 semantic layouts with the same slots, so any script builds in any of them; only the look changes. Galleries hold three pictures in every built-in template.

## Choosing by tone

| Signal in the brief | Lean towards |
| --- | --- |
| Investors, founders, demo day | aurora, venture, northstar; launchpad or ember for a dark stage |
| Board, finance, formal | boardroom, ledger, consulting, briefing |
| Data-heavy, charts on most slides | quarterly, metrics, ledger-dark, dataflow |
| Photography, product pictures | gallery, lookbook, studio-noir, portfolio |
| Engineering, developer audience | devday, terminal, circuit, cloud |
| Teaching, children, workshops | classroom, kids, workshop, lecture |
| Calm, neutral, unknown audience | studio, mono, swiss, nordic |
| Projected in a bright room | light templates; dark ones read best on screens and stages |
| Printed handouts or PDF reading | light, serif or high-contrast: paper, lecture, consulting, mono |
