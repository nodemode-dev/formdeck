# Story gate

Run on the slide plan before it goes to slide-script-author.

- [ ] Deck type named and its arc from deck-arcs.md applied (or the deviation stated)
- [ ] One-sentence point written; it appears on the title or closing slide
- [ ] Slide count inside the arc's range, or exactly the number the person asked for
- [ ] Plan has one line per slide: number, layout, claim title, evidence ids
- [ ] Reading the titles alone tells the story; no bare topic titles except title, agenda, sections, closing labels
- [ ] Every claim has evidence from the intake; nothing invented
- [ ] Numbers sit on stats, bigNumber, chart or table slides, each with unit and comparison
- [ ] No slide plans more than 6 bullets or more than one chart
- [ ] Agenda present only for 4 to 7 parts and 8 or more slides; agenda items match section names
- [ ] Notes planned for every content slide, with the source id
- [ ] Closing carries the point and the next step, not only thanks
