# Handoff gate

Run before sending the summary.

- [ ] Every slide you built or changed has a `ready` or `question` handoff; you set no review verdict
- [ ] Each open question has one comment on its slide, and the summary names the same questions
- [ ] Person's comments: each addressed one has a reply saying what changed, then resolved; unaddressed ones left open and named
- [ ] Summary sent in the order: deck and template, what to look at first, open questions, left as is, not done, how to undo
- [ ] Exports (only if asked) written; the summary quotes the exact path from the tool result
- [ ] Any undo used the narrowest scope that fixed the problem, and the summary says what was reverted
