# PDF gate

Run before reporting.

- [ ] Every path given to the tool was absolute; split's `out` folder existed
- [ ] info was run first for an unknown or possibly locked PDF
- [ ] to_deck chosen only when the original look must stay; ingest chosen when the person needs editable slides
- [ ] Output paths quoted exactly as the tool returned them, with page counts
- [ ] Extracted pictures reported with their media ids if they are meant for slides
- [ ] Before redact, find ran with the same query or preset and the person knew what would go; the redacted file's path and match count reported
- [ ] Crop described as hiding, not removing, content
- [ ] Window-only jobs (sign, comment and reply, compress, watermark, organize, protect) pointed to File > PDF tools instead of improvised
